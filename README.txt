==============================================================================
                    AroundWorldNG (AWNG) — Real-World Generator
                             для BeamNG.drive (v0.39+)
==============================================================================

AroundWorldNG — это модульный процедурный генератор карт и окружения реального
мира для BeamNG.drive. Он объединяет данные открытых геоинформационных систем
(OpenStreetMap, высоты DEM Terrarium) и спутниковые данные для создания
полноценных уровней и бесконечных процедурных планет.

------------------------------------------------------------------------------
 1. БЫСТРЫЙ СТАРТ (ИГРА В РЕЖИМЕ ПЛАНЕТЫ)
------------------------------------------------------------------------------
1. Скопируйте файл `aroundworldng_planet.zip` и ZIP-пакет нужного региона 
   (например, `aroundworldng_northwestern-fed-district.zip`) в вашу папку модов:
   %LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\
   (Архивы распаковывать НЕ нужно, оставляйте их в .zip).
2. Запустите BeamNG.drive.
3. Откройте «Свободный заезд» (Freeroam) -> выберите «AroundWorldNG - Планета».
4. Выберите точку спавна или выберите желаемый город на интерактивной карте.
5. Нажмите «Высадиться» (Land). Карта процедурно генерируется на лету!

------------------------------------------------------------------------------
 2. СБОРКА СОБСТВЕННОГО РЕГИОНА / КАРТЫ (AROUNDWORLDNG MAP STUDIO)
------------------------------------------------------------------------------
1. Установите Python 3.13 с официального сайта:
   https://www.python.org/downloads/windows/
   ВАЖНО: при установке обязательно отметьте галочки:
   [x] "tcl/tk and IDLE"
   [x] "py launcher"
   [x] "Add python.exe to PATH"
2. Запустите `AroundWorldNG.bat` двойным кликом.
   При первом запуске автоматически выполнится настройка окружения (.venv)
   и загрузятся необходимые библиотеки.
3. В открывшемся графическом окне Map Studio:
   - Выберите готовый регион/страну из каталога, либо включите рамку
     произвольной области («Выбрать область на карте»).
   - Настройте архитектурный стиль зданий (панельки, европейские кварталы,
     современные высотки, частный сектор).
   - Нажмите кнопку «Собрать карту для BeamNG».
4. Генератор автоматически скачает высоты и дороги OSM, нарежет тайлы
   и упакует готовый `aroundworldng_<регион>.zip` прямо в вашу папку mods!
5. Перезапустите BeamNG.drive и высаживайтесь в собранной локации.

------------------------------------------------------------------------------
 3. ТРЕБОВАНИЯ И СОВМЕСТИМОСТЬ
------------------------------------------------------------------------------
* Операционная система: Windows 10 / 11 (64-bit)
* Игра: BeamNG.drive 0.39.4, 0.40 и новее
* Python: 3.13+ (для работы генератора Map Studio)
* Свободное место на диске: от 2 ГБ для базового ядра и от 5-10 ГБ при сборке
  крупных стран с плотной дорожной сетью.
