# AroundWorldNG — Генератор реалистичных карт BeamNG.drive по данным Яндекс Карт и OSM

Инструмент для генерации детализированных локаций для BeamNG.drive на основе:
- Спутниковых снимков высокого разрешения Яндекс Карт
- Данных рельефа (DEM)
- Векторных данных дорог, зданий, лесов и водоемов OpenStreetMap

## Архитектура проекта

```
aroundworldng/
├── core/                   # Базовые типы, конфигурация, гео-преобразования
│   ├── config.py           # Настройки качества, путей и параметров генерации
│   └── projection.py       # Преобразование координат (Яндекс EPSG:3395 <-> WGS84 EPSG:4326 <-> Локальные метры)
├── fetchers/               # Загрузка внешних геоданных
│   ├── yandex_sat.py       # Скачивание и сшивание спутниковых тайлов Яндекс
│   ├── elevation.py        # Загрузка карты высот (DEM)
│   └── osm.py              # Запрос дорог, рек, зданий и лесов через Overpass API
├── processing/             # Обработка и слияние данных
│   ├── heightmap.py        # Интерполяция и сохранение 16-bit heightmap
│   ├── road_carver.py      # Сглаживание рельефа под дорогами
│   ├── exclusion.py        # Защитная буферизация дорог (удаление машин/домов с асфальта)
│   └── splatmaps.py        # Генерация масок материалов (асфальт, трава, грязь, скалы)
├── exporter/               # Сборка готового мода BeamNG.drive
│   ├── level_builder.py    # Сборка дерева папок уровня
│   ├── decal_roads.py      # Генерация сплайнов DecalRoad и MeshRoad
│   ├── forest.py           # Генерация расстановки деревьев (managedData.json)
│   └── templates/          # Базовые JSON-шаблоны для движка Torque3D
├── ui/                     # Интерфейс управления
│   ├── cli.py              # Консольный интерфейс
│   └── web/                # Интерактивная карта для выбора области/маршрута
├── main.py                 # Главная точка входа
└── requirements.txt        # Python-зависимости
```
