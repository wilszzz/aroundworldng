# AroundWorldNG (AWNG)

> **Модульный процедурный генератор карт и окружения реального мира для BeamNG.drive (движок Torque3D v9 / PBR 1.5).**

[![Python 3.13](https://img.shields.io/badge/python-3.13-blue.svg)](https://www.python.org/downloads/windows/)
[![BeamNG.drive](https://img.shields.io/badge/BeamNG.drive-0.39%2B-orange.svg)](https://beamng.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## 🌟 Ключевые возможности

* 🌍 **Бесконечный стриминг мира (World Streaming):**  
  Генерация дорог, зданий, рельефа и растительности на лету прямо в LuaJIT BeamNG. Перемещение на сотни километров без экранов загрузки.
* 🏙️ **Умная процедурная архитектура:**  
  Честная 3D-экструзия реальных контуров OpenStreetMap: многоэтажки, хрущевки, частный сектор, автоматическое выравнивание фундаментов, балконы, крыши с парапетами и 100% твердая физическая коллизия.
* 🛣️ **Точная геометрия дорог:**  
  Гладкие стыки тайлов (без ступеней и обрывов), плавные въезды на мосты и эстакады, реальная разметка и ширина полос.
* ⚡ **Турбо-бюджет начальной загрузки:**  
  Динамический бюджет кадра (24 мс на экране высадки для 5-кратного ускорения старта и строгие 4 мс при езде для стабильных 60+ FPS).
* 🖥️ **AroundWorldNG Map Studio:**  
  Автономный лаунчер с современным темным интерфейсом (`AroundWorldNG.bat`): интерактивная карта мира, выбор регионов, настройка стилей застройки и экспорт мода в один клик.

## 🚀 Быстрый старт

### Игра в режиме «Планета»
1. Скопируйте **`aroundworldng_planet.zip`** и архив нужного региона (например, `aroundworldng_northwestern-fed-district.zip`) в папку модов:
   ```text
   %LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\
   ```
   *(Архивы распаковывать не нужно)*.
2. Запустите BeamNG.drive $\to$ **Свободный заезд (Freeroam)** $\to$ выберите уровень **AroundWorldNG - Планета**.
3. На интерактивной карте выберите точку спавна или желаемый город и нажмите **Высадиться (Land)**.

---

### Сборка собственного региона или готовой карты (Map Studio)
1. Убедитесь, что установлен [Python 3.13+](https://www.python.org/downloads/windows/) (с галочками `tcl/tk and IDLE` и `py launcher`).
2. Запустите файл:
   ```bat
   AroundWorldNG.bat
   ```
3. В открывшейся графической студии выберите один из **двух режимов**:
   * **«Пак для Планеты» (Стриминг)**:
     - Создает `aroundworldng_<регион>.zip` для глобального открытого мира «AroundWorldNG - Планета».
     - Позволяет бесшовно путешествовать по огромным территориям (целые страны и области).
     - Дороги и окружение генерируются на лету процедурным движком.
   * **«Готовая карта» (Автономный уровень BeamNG)**:
     - Запекает выбранный прямоугольник (BBox) или пресет (Кудрово, Мурино, Москва-Сити) в полноценный отдельный уровень `levels/awng_<имя>/` (`awng_<имя>.zip`).
     - Появляется прямо в главном меню Freeroam среди стандартных карт BeamNG.
     - **Мгновенная загрузка (3–5 секунд)**: статический рельеф `theTerrain.ter`, дороги DecalRoad, 3D-здания с коллизиями и точка спавна уже запечены.
4. Нажмите кнопку сборки — архив автоматически соберется и установится в вашу папку `mods`. Перезапустите BeamNG.drive!

## ⚙️ Настройки производительности в игре

В меню мода (клавиша `F10` или окно при выборе точки) доступны пресеты детализации:
* **Potato / Low:** максимальная скорость загрузки и высокий FPS на слабых ПК (сокращенный радиус, минимум травы и деревьев).
* **Balanced (по умолчанию):** оптимальный баланс дальности прорисовки и детальности.
* **High / OASIS:** ультра-дальность прорисовки рельефа (до 4-8 км) и максимальная плотность лесных массивов.

## 📁 Структура репозитория

```text
aroundworldng/
├── AroundWorldNG.bat              # Главный графический лаунчер Map Studio
├── Setup.bat                      # Автоматическая настройка виртуального окружения Python
├── aroundworldng/                 # Ядро генератора и сборщика пакетов (Python)
│   ├── country_ui.py              # Интерфейс Map Studio на CustomTkinter
│   ├── export_standalone.py       # Экспортер автономных готовых карт BeamNG
│   ├── builder_map.py             # Растеризация и проекции карт
│   ├── build_country.py           # Конвертер геоданных OSM в тайлы
│   └── country_fetch.py           # Загрузчик высот DEM и геоданных
├── mod/                           # Мод для BeamNG.drive
│   ├── lua/ge/extensions/e2r/     # Рантайм-генератор LuaJIT (движок мира)
│   │   ├── generator.lua          # 3D-геометрия дорог, домов и рельефа
│   │   ├── native.lua             # Потоковый планировщик тайлов
│   │   └── world.lua              # Логика уровня, спавна и камеры
│   ├── scripts/aroundworldng/     # Автозагрузка расширения
│   └── aroundworldng/planet/      # Базовые оффлайн-карты и береговые линии
├── tests/                         # Автоматические тесты геометрии и байткода
├── PROJECT_ARCHITECTURE_AND_ROADMAP.md # Архитектурный манифест проекта
└── README.md
```
